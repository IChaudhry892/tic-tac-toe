# Tic Tac Toe

A simple Tic Tac Toe game built with HTML, CSS, and JavaScript.

🎮 **Play it here:** [https://beautiful-douhua-45b2d2.netlify.app/](https://beautiful-douhua-45b2d2.netlify.app/)

## What I Learned

Making this project, I learned about:
- JavaScript event listeners and how to handle user interactions
- Adding event listeners to multiple HTML elements efficiently
- Using `document.getElementById()` and `document.querySelector()` to select HTML elements with JavaScript
- Importing and exporting modules to access variables between scripts and organize code better
- How to make modal overlays using HTML, CSS, and JavaScript
